# הזמנות חתונה בוואטסאפ

אפליקציה מקומית לשליחת הזמנות חתונה בוואטסאפ לרשימת מוזמנים מקובץ אקסל, או שנוספה ידנית.

## איך זה עובד

1. מריצים את השרת **במחשב שלכם** (ראו הערה על סביבות ענן/דפדפן מרוחק בסוף המסמך).
2. פותחים את הדפדפן בכתובת `http://localhost:3000`.
3. סורקים קוד QR עם הוואטסאפ בטלפון (הגדרות ← מכשירים מקושרים ← קישור מכשיר) - בדיוק כמו בוואטסאפ ווב הרגיל. אפשר לחבר יותר ממספר וואטסאפ אחד (למשל שלך ושל בן/בת הזוג) - ראו "כמה חשבונות וואטסאפ" למטה.
4. מעלים קובץ אקסל (`.xlsx`) עם העמודות **שם המוזמן** ו-**מספר טלפון**, ואופציונלית גם **צד** - ו/או מוסיפים מוזמנים בודדים ידנית בטופס "הוספת מוזמן" (שם + טלפון + צד), בלי צורך בקובץ אקסל בכלל.
5. בוחרים למי לשלוח (אפשר הכל, אפשר חלק), כותבים הודעה כללית - אפשר לבחור נקודת התחלה מתוך "תבנית מוכנה" (כמה נוסחים מוכנים, כולל גם הודעה כללית בלי שם) ולערוך אותה כרצונכם, ואפשר להשתמש ב-`{{שם}}` שיוחלף בשם כל מוזמן. אפשר גם להעלות תמונה או סרטון להזמנה - הם יישלחו לכולם עם ההודעה כתיאור מתחת.
6. אם רוצים לערוך שם/טלפון/צד של מוזמן מסוים, או לתת לו הודעה אישית (במקום התבנית הכללית), לוחצים על כפתור העיפרון לצידו ברשימה, מעדכנים ושומרים (אפשר גם לאפס את ההודעה האישית בחזרה לתבנית הכללית).
7. לוחצים "שליחת הזמנות". ההודעות נשלחות אחת אחרי השנייה עם השהיה אקראית ביניהן כדי להפחית את הסיכוי לחסימה, כל מוזמן מהחשבון המתאים לצד שלו. כל הודעה כוללת אוטומטית גם שאלת אישור הגעה - ראו "אישור הגעה אוטומטי" למטה.

ההודעות נשלחות מהמספר האישי שלכם (כמו וואטסאפ ווב), ולכן אין צורך באישור עסקי של מטא, אבל חשוב לא לשלוח בכמויות גדולות מדי בבת אחת.

## התקנה

דורש [Node.js](https://nodejs.org) גרסה 20 ומעלה.

```bash
npm install
```

להרצה רגילה (מומלץ - מהיר יותר):

```bash
npm run build
```

```bash
npm start
```

לפיתוח, עם רענון אוטומטי בכל שינוי בקוד:

```bash
npm run dev
```

לאחר ההרצה, פותחים דפדפן בכתובת שמוצגת בטרמינל (בדרך כלל `http://localhost:3000`).

הפעם הראשונה תדרוש סריקת QR לכל חיבור. בפעמים הבאות החיבור יישמר אוטומטית (כל חיבור בתיקיית `.baileys_auth_<מזהה>` משלו - לא לשתף/להעלות תיקיות אלו לאף אחד, הן כוללות הרשאת גישה מלאה לחשבונות הוואטסאפ שלכם).

## כמה חשבונות וואטסאפ (למשל את ואת בן/בת הזוג)

בלשונית "חיבורי וואטסאפ" יש חיבור ברירת מחדל אחד, ואפשר להוסיף עוד עם "הוספת חיבור וואטסאפ" - נותנים לו שם (למשל "אושרי" או "מיקה") וסורקים לו QR נפרד מהטלפון של אותו אדם. שמות החיבורים נשמרים בין הפעלות (`data/accounts.json`), כך שההתאמה לעמודת "צד" לא נשברת אחרי הפעלה מחדש.

- **אם יש חיבור אחד בלבד**, כל המוזמנים נשלחים דרכו, בלי קשר לעמודת "צד".
- **אם יש שני חיבורים ומעלה**, עמודת "צד" בכל מוזמן חייבת להתאים (במדויק, לא רגיש לרישיות/רווחים) לשם שנתתם לאחד החיבורים - למשל אם הגדרתם חיבור בשם "אושרי" וחיבור בשם "מיקה", ערך "אושרי" בעמודת הצד ישלח דרך החיבור של אושרי. מוזמן עם צד שלא מזוהה (או בלי צד בכלל) יסומן באזהרה ברשימה ולא ניתן יהיה לבחור אותו, עד שיתקנו לו את הצד בעריכה.
- אפשר לשנות שם חיבור, להתנתק ממנו, או להסיר אותו לגמרי (רק אם יש יותר מחיבור אחד) - הכל בסעיף חיבורי הוואטסאפ.

## פורמט קובץ האקסל

| שם המוזמן | מספר טלפון | צד |
|---|---|---|
| דנה כהן | 052-1234567 | אושרי |
| יוסי לוי | 0501234567 | מיקה |

עמודת "צד" אופציונלית - אם לא מוסיפים אותה (או שיש חיבור וואטסאפ אחד בלבד) הכל עובד כרגיל בלי צורך בה.

מספרי טלפון ישראליים (עם או בלי 0 בהתחלה, עם או בלי מקפים) מזוהים אוטומטית. אם המספר לא תקין הוא יסומן ברשימה ולא ניתן יהיה לבחור אותו.

## תמונה/סרטון ההזמנה והודעות אישיות

- אפשר להעלות תמונה **או** סרטון להזמנה - הוא משותף לכולם, מעלים אותו פעם אחת בלשונית "הודעה ושליחה", וכל מי שנבחר יקבל אותו עם ההודעה (הכללית או האישית שלו) בתור כיתוב מתחתיו. אפשר להחליף/להסיר בכל שלב לפני השליחה. גודל מקסימלי לקובץ: 64MB - אבל וואטסאפ עצמו עלול לדחות סרטונים כבדים/ארוכים מדי, אז עדיף לשמור על סרטון קצר וקליל.
- הודעה אישית היא פר-מוזמן: אם הוגדרה למוזמן מסוים, היא תישלח לו *במקום* ההודעה הכללית (אך עדיין תומכת ב-`{{שם}}` אם רוצים). מוזמנים בלי הודעה אישית ימשיכו לקבל את ההודעה הכללית.

## אישור הגעה אוטומטי (RSVP)

לכל הודעה שנשלחת מתווספת אוטומטית שורה שמבקשת מהמוזמן להשיב **כן / לא / אולי**. כשהמוזמן משיב בוואטסאפ, השרת קורא את התשובה ומעדכן את הרשימה בעצמו - אין צורך לעשות כלום ידנית:

- **כן** → הבוט שואל אוטומטית "כמה אנשים בסך הכל מגיעים?" ומחכה למספר. אחרי שהמוזמן עונה מספר, הסטטוס מתעדכן ל"מגיע (X)".
- **לא** → מסומן כ"לא מגיע".
- **אולי** → מסומן כ"אולי".
- אם המוזמן שולח משהו שלא מובן - הבוט ישאל שוב פעם אחת "מגיעים? כן/לא/אולי" (ולא יטריד שוב אם כבר ענה בעבר).

**תיקון תשובה** - מוזמן יכול לתקן תשובה בכל שלב, גם אחרי שכבר ענה:
- כותב **"סטטוס"** → הבוט שואל מחדש "מגיעים? כן/לא/אולי".
- כותב **"תקן"** → הבוט שואל מחדש כמה אורחים מגיעים (רק אם הסטטוס כבר "כן" - אחרת יבקש קודם לענות כן/לא/אולי).

בראש הדף יש דשבורד עם המספרים המרכזיים בזמן אמת (מגיעים/לא מגיעים/אולי/ממתינים + סטטוס חיבורי הוואטסאפ), ולכל מוזמן ברשימה יש תג צבעוני עם הסטטוס העדכני שלו. הכל מתעדכן אוטומטית כל כמה שניות כשמגיעות תשובות חדשות.

חשוב: הבוט מגיב **רק** למי שכבר שלחתם לו הזמנה (כדי לא להגיב אוטומטית לכל מי שכותב למספר שלכם), והתשובה חוזרת מהחשבון (הצד) שממנו נשלחה ההזמנה המקורית לאותו מוזמן.

כל הנתונים נשמרים בתיקיית `data/` ונטענים בחזרה בכל הפעלה, כך שאפשר להפעיל/לכבות את השרת בלי לאבד כלום:

| קובץ | מה נשמר |
|---|---|
| `data/guests.json` | רשימת המוזמנים, מי כבר הוזמן וכל תשובות ה-RSVP |
| `data/accounts.json` | שמות חיבורי הוואטסאפ (ההתאמה לעמודת "צד") |
| `data/invitation-media.*` | תמונת/סרטון ההזמנה שהועלו |

## סינון, תזכורות וייצוא

- **סינון לפי סטטוס** - מתחת לתיבת החיפוש יש שורת כפתורי סינון לפי סטטוס RSVP (מגיעים/לא מגיעים/אולי/ממתינים/טרם נשלח). "בחירת הנראים" בוחר רק את מה שמוצג כרגע (בהתאם לסינון והחיפוש), לא את כל הרשימה.
- **תזכורת בלחיצה אחת** - הכפתור "תזכורת לממתינים" מסנן ובוחר אוטומטית את כל מי שכבר קיבל הזמנה אבל עדיין לא ענה, טוען את תבנית ה"תזכורת" בתיבת ההודעה, ומעביר ללשונית השליחה כדי שתוכלו לבדוק ולשלוח.
- **ייצוא לאקסל** - הכפתור "ייצוא לאקסל" מוריד קובץ `guests.xlsx` עם שם, טלפון, צד, סטטוס אישור הגעה וכמות האורחים לכל מוזמן - שימושי לשליחה לספק הקייטרינג/האולם.
- **מחיקה** - אפשר למחוק מוזמן בודד מהרשימה, או לנקות את כל הרשימה ("ניקוי"). שתי הפעולות מבקשות אישור קודם - כדאי לייצא לאקסל לפני ניקוי מלא.

## הערות חשובות

- זו לא ה-API הרשמי של וואטסאפ עסקי, אלא חיבור ישיר (WebSocket) לפרוטוקול וואטסאפ ווב (ספריית [Baileys](https://github.com/WhiskeySockets/Baileys)) - בלי דפדפן וללא Chromium. זה כרוך בסיכון תיאורטי לחסימה זמנית אם שולחים כמויות גדולות מאוד או שהמספרים לא רשומים בוואטסאפ - לשימוש אישי בהיקף של הזמנת חתונה (עשרות עד מאות מוזמנים) זה בטוח בפועל.
- אין לשתף את תיקיות `.baileys_auth_*` עם אף אחד - הן מהוות גישה מלאה לחשבונות הוואטסאפ שלכם.
- לחיצה על "התנתקות" בחיבור מסוים תנתק רק אותו ותאפשר לו סריקת QR חדש - החיבורים האחרים ימשיכו לעבוד.

## אם קוד ה-QR לא מופיע

האפליקציה מתחברת ישירות לשרתי וואטסאפ דרך האינטרנט. אם היא רצה **בתוך סביבת ענן/קונטיינר מרוחק** (כמו Claude Code on the web) שחוסמת גישה יוצאת לאתרים חיצוניים, קוד ה-QR לעולם לא ייווצר - זו לא תקלה בקוד אלא מדיניות רשת של הסביבה. הריצו את השרת במחשב האישי שלכם עם חיבור אינטרנט רגיל כדי שזה יעבוד.
אם אתם כן מאחורי פרוקסי (למשל ברשת חברה), אפשר להגדיר משתנה סביבה `HTTPS_PROXY` לפני ההרצה (`HTTPS_PROXY=http://... npm start`) והשרת ישתמש בו אוטומטית.

## מבנה הפרויקט

האפליקציה בנויה ב-[Next.js](https://nextjs.org) (App Router) עם TypeScript ו-Tailwind CSS. חשוב להריץ אותה כשרת Node אחד ורציף (`npm start`) - חיבורי הוואטסאפ הם חיבורי WebSocket חיים שנשמרים בזיכרון התהליך, ולכן היא לא מתאימה לפריסה serverless.

| תיקייה | תפקיד |
|---|---|
| `app/` | הדפים ומסלולי ה-API (`app/api/**/route.ts`) |
| `components/` | רכיבי ה-UI (רשימת מוזמנים, חיבורים, עורך ההודעה, התקדמות שליחה) |
| `lib/server/` | הלוגיקה בצד השרת: חיבורי וואטסאפ, אחסון מוזמנים, קריאת/כתיבת אקסל, RSVP, תור השליחה |
| `lib/` | טיפוסים, תבניות הודעה וניהול ה-state בצד הלקוח |
| `data/` | הנתונים השמורים (לא נכנס ל-git) |
