# הזמנות חתונה בוואטסאפ

אפליקציה מקומית לשליחת הזמנות חתונה בוואטסאפ לרשימת מוזמנים מקובץ אקסל.

## איך זה עובד

1. מריצים את השרת במחשב שלכם.
2. פותחים את הדפדפן בכתובת `http://localhost:3000`.
3. סורקים קוד QR עם הוואטסאפ בטלפון (הגדרות ← מכשירים מקושרים ← קישור מכשיר) - בדיוק כמו בוואטסאפ ווב הרגיל.
4. מעלים קובץ אקסל (`.xlsx`) עם שתי עמודות: **שם המוזמן** ו-**מספר טלפון**.
5. בוחרים למי לשלוח (אפשר הכל, אפשר חלק), כותבים הודעה (אפשר להשתמש ב-`{{שם}}` שיוחלף בשם כל מוזמן), ולוחצים "שליחת הזמנות".
6. ההודעות נשלחות אחת אחרי השנייה עם השהיה אקראית ביניהן כדי להפחית את הסיכוי לחסימה.

ההודעות נשלחות מהמספר האישי שלכם (כמו וואטסאפ ווב), ולכן אין צורך באישור עסקי של מטא, אבל חשוב לא לשלוח בכמויות גדולות מדי בבת אחת.

## התקנה

דורש [Node.js](https://nodejs.org) גרסה 18 ומעלה.

```bash
npm install
npm start
```

בפעם הראשונה ההתקנה תוריד גם דפדפן כרום פנימי (למנוע whatsapp-web.js), זה יכול לקחת כמה דקות.

לאחר ההרצה, פותחים דפדפן בכתובת שמוצגת בטרמינל (בדרך כלל `http://localhost:3000`).

הפעם הראשונה תדרוש סריקת QR. בפעמים הבאות החיבור יישמר אוטומטית בתיקיית `.wwebjs_auth` (לא לשתף/להעלות אותה - היא כוללת הרשאת גישה לחשבון הוואטסאפ שלכם).

## פורמט קובץ האקסל

| שם המוזמן | מספר טלפון |
|---|---|
| דנה כהן | 052-1234567 |
| יוסי לוי | 0501234567 |

מספרי טלפון ישראליים (עם או בלי 0 בהתחלה, עם או בלי מקפים) מזוהים אוטומטית. אם המספר לא תקין הוא יסומן ברשימה ולא ניתן יהיה לבחור אותו.

## הערות חשובות

- זו לא ה-API הרשמי של וואטסאפ עסקי, אלא אוטומציה של וואטסאפ ווב (ספריית `whatsapp-web.js`). זה כרוך בסיכון תיאורטי לחסימה זמנית אם שולחים כמויות גדולות מאוד או שהמספרים לא רשומים בוואטסאפ - לשימוש אישי בהיקף של הזמנת חתונה (עשרות עד מאות מוזמנים) זה בטוח בפועל.
- אין לשתף את תיקיית `.wwebjs_auth` עם אף אחד - היא מהווה גישה מלאה לחשבון הוואטסאפ שלכם.
- לחיצה על "התנתקות" תנתק את חשבון הוואטסאפ מהאפליקציה ותאפשר סריקת QR חדש.
